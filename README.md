# 医学研究のためのRによる統計解析入門 — サポートページ（GitHub レポジトリ）

オーム社 加葉田大志朗 著『医学研究のためのRによる統計解析入門』（2023年9月発売）の読者向けサポートページ（GitHub レポジトリ）です．本書で使用する練習用データファイルと，本編中のRスクリプトを配布しています．

## オンラインで読む（GitHub Pages）

- **Rコードと実行結果**: <https://kabajiro.github.io/Rcode_Ohmsha_2023/Rcode.html>

※ このサポートページに戻れるよう別タブで開きたい場合は，**Ctrl + クリック**（Windows）または **⌘ + クリック**（Mac），あるいは右クリック→「新しいタブで開く」をご利用ください．

## 正誤表

刊行後に判明した誤りと訂正の内容は，以下のページにまとめています．

- **正誤表**: <https://kabajiro.github.io/Rcode_Ohmsha_2023/errata.html>

誤りと思われる箇所を見つけた場合は，オーム社の[書籍お問合せフォーム](https://www.ohmsha.co.jp/contact/book.php?isbn=978-4-274-23090-5)からお知らせください．

## ダウンロード方法

Code → Download zip から一括ダウンロードできます．解凍してからご利用ください．

## データファイル

### original.csv
練習用データファイル．csv形式．

### original.xlsx
練習用データファイル．xlsx形式．<br>
内容はoriginal.csvと同じ．

### new.csv
練習用データファイル．csv形式．<br>
本編中でoriginal.csvを編集して作成されるファイルと同じ内容です．<br>
本編中でデータ整形ができなかった場合はこちらをご利用ください．

### Rcode.html

### FinalReport.Rmd
